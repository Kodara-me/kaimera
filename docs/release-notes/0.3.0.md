# Kaimera 0.3.0

*Animation length, sprite sheets and a Windows icon* · 2026-10-30

Kaimera creates and edits images with AI models. It is a Qt 6 Widgets desktop
application for Linux, macOS and Windows that runs its jobs on a
[Nukleus](https://github.com/jstmichel/nukleus) service.

## Changes in 0.3.0

- **Animation length**: the Animate form has a Short / Medium / Long choice (33, 41 or 81
  frames) with a summary of the frame count and the duration, and the loop's duration when
  Loop is on. The choice starts from the selected model's `videoFrames` default and stays
  as set while the model stays the same. Every animation now sends `videoFrames` and `fps`
  (the model's default, else 16).
- **PNG sprite sheet**: Save as on an animation entry offers a PNG sprite sheet beside the
  MP4 video, for game engines. Every frame is at full size, in playback order, in a grid of
  `ceil(sqrt(n))` columns with transparent unused cells, and the suggested name ends with
  the grid, such as `animation-3x2.png`.
- **Windows icon**: `kaimera.exe` now carries the application icon, so Explorer, the Start
  menu and pinned shortcuts show it instead of the generic executable icon. The
  multi-size `assets/icons/kaimera.ico` is built from the PNG exports by
  `scripts/make-ico.py`, which uses the Python standard library only.
- **Windows build**: Kaimera builds with MSVC 2022 and Qt 6.8.3, with Qt Multimedia, the
  Nukleus SDK and Ardoise. The developer build is described in `CONTRIBUTING.md`.

## Requirements

Unchanged from 0.2.0: Qt 6.5 or newer with Multimedia, Network, WebSockets and Widgets
(with the FFmpeg backend) and LinguistTools, and a reachable Nukleus service with its
models. Animation needs Nukleus 0.3 or newer with ffmpeg on the service and an animation
model with all its files. The Nukleus SDK is cloned at tag v0.3.0 when no sibling checkout
or installed package is found.

## Notes

CI builds and tests on Linux only, with offscreen rendering. On Windows, `ctest` passes 70
cases and fails 3 `canvas-test` cases about widget geometry on the offscreen platform
(preview badge position, a horizontal scroll bar in a narrow panel, and an overlay
position); they have not been checked with a real window yet, and macOS builds still need
checks on a real desktop. There is no Windows installer or deployment script yet.
