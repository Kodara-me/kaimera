# Kaimera 0.4.0

*Train and use LoRAs* · 2026-11-10

Kaimera creates and edits images with AI models. It is a Qt 6 Widgets desktop
application for Linux, macOS and Windows that runs its jobs on a
[Nukleus](https://github.com/Kodara-me/nukleus) service.

## Changes in 0.4.0

- **Train a LoRA**: the "Train a LoRA…" button in the identity section of the toolbar
  opens a form with these fields:
  - an image folder: the PNG and JPEG files directly in it, sorted by name, from 1 to 64
    images;
  - a name, prefilled from the folder name;
  - a trigger word;
  - a base `.safetensors` checkpoint, which must be SDXL;
  - a number of steps, 1500 by default.

  Each image is captioned with the trigger word, followed by the text of a `.txt` file of
  the same name when there is one. The form checks the name against installed companions
  and the caption lengths before it sends anything. The training runs as one job with the
  progress pill. When it ends, the new LoRA appears in Available Models without a
  restart. Kaimera remembers its trigger word and base model. Closing Kaimera during a
  training asks for confirmation first, because the service stops a training when its
  client disconnects.
- **Use LoRAs**: step 1 of the New image card has a LoRAs control. It can hold up to 8
  installed LoRAs, each with a weight from 0 to 2 in steps of 0.05 (1.0 by default). The
  remembered trigger words are added to the prompt untranslated, after the shot clauses
  and before your text. LoRAs apply only to the New image card's Generate: edits, the
  identity panel and Kira Sparkle send none. New Image clears the choice, and a preset
  change keeps it.
- **Nukleus source**: the Nukleus SDK is now cloned from `Kodara-me/nukleus` at tag
  v0.6.0.

## Requirements

Qt 6.5 or newer with Multimedia, Network, WebSockets and Widgets (with the FFmpeg backend)
and LinguistTools, and a reachable Nukleus service with its models. The LoRA features
need Nukleus 0.6 or newer: training also needs the LoRA trainer set up on the service
(see Nukleus `docs/lora-training.md`). The other features keep the requirements of
0.3.0.

## Notes

CI builds and tests on Linux only, with offscreen rendering. On Windows, the same 3
`canvas-test` cases about widget geometry on the offscreen platform still fail. They have
not been checked with a real window yet. There is no Windows installer yet.
