# Kaimera 0.2.0

*Image animation* · 2026-10-24

Kaimera creates and edits images with AI models. It is a Qt 6 Widgets desktop
application for Linux, macOS and Windows that runs its jobs on a
[Nukleus](https://github.com/jstmichel/nukleus) service.

This is the first published release. Version 0.1.0 was prepared on 2026-10-19 but never
tagged, so its notes remain in [0.1.0.md](0.1.0.md) and everything in them is part of this
release.

## Changes in 0.2.0

- **Animate**: a new button in the toolbar (**Animer** in French) turns the selected image
  into a short video through Nukleus. A floating form asks for the motion prompt, an
  optional end image attached with the paperclip, a **Loop** switch (ping-pong, shown when
  the service offers it) and, when several animation models are installed, the model. The
  prompt is translated into English like the edit instructions, and the video keeps the
  start image's aspect ratio. The job shows a progress tile in the session history, then
  the first frame with a play mark.
- **Playback and saving**: a selected animation plays in a loop in the preview, a click
  pauses or resumes it, and the badge shows its size, frame count and rate. Save as writes
  the MP4 as received. Crop, upscale, downscale, sharpen and the edit tools are disabled on
  an animation.
- **Dependencies**: playback uses Qt Multimedia with its FFmpeg backend, now a build
  requirement. Builds without a sibling Nukleus checkout or an installed SDK clone the
  Nukleus SDK at tag v0.3.0 (it was v0.1.0).
- **Translations**: every new string is translated into French.

## Highlights

- **Guided generation**: a New image card that walks through the look (preset and
  to-scale format tiles), the camera shot, up to four reference images, the prompt and
  what to avoid. Generations queue on the service, each behind a history tile.
- **Editing**: an edit bubble over the preview with three editing qualities (Fast,
  Balanced, Quality), reference images, crop, 2× upscale, Lanczos downscale and a light
  sharpening pass.
- **Identities**: front, profile and three-quarter portraits saved as `.kiraid`
  packages, then attached to generations or applied to edits.
- **Kira Sparkle**: a chat that understands a request, proposes an image with its
  shot, ratio and prompt, and creates it once accepted.
- **Prompt help**: translation into English before submission, Sparkles improvement of
  prompts and instructions, and Danbooru tags for tag-based models with an optional
  local dictionary.
- **Translations**: English and French, following the system language.

## Install

```sh
curl -fsSL https://github.com/Kodara-me/kaimera/releases/latest/download/get-kaimera.sh | sh
```

## Requirements

CMake 3.24+, a C++20 compiler, Qt 6.5+ with Widgets, Network, WebSockets, SVG, Multimedia
(with its FFmpeg backend) and LinguistTools, LibArchive, and a reachable Nukleus 0.1
service with its models. Animation needs Nukleus 0.3 with ffmpeg on the service and an
animation model with all its files. [Ardoise](https://github.com/jstmichel/ardoise) 0.1 and
the Nukleus SDK are used when installed, otherwise CMake clones their pinned tags.

## Notes

Kaimera was previously named Kira Canvas: on its first start it copies the settings and
the Danbooru dictionary saved under that name, and leaves the originals in place. CI builds
and tests on Linux only, with offscreen rendering; macOS and Windows builds still need
checks on real desktops. The PNG sprite sheet export of an animation, for games, is not
part of this release.
